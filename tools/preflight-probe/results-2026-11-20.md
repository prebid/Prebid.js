# Preflight probe results, 2026-11-20

This run used master at `28c664c19` and one network vantage point. See [README.md](README.md) for the method and
the classes. The table was generated with `node tools/preflight-probe/probe.mjs --from out/results.json`, after the
single live run.

The capture ran 670 specs (bid adapters, user ID and RTD modules). It found 82 modules whose request carries a
preflight trigger: 68 bidders, 10 user ID modules and 4 RTD providers. The CodeQL rule only looks at
`*BidAdapter` files, and only for the exact string `'application/json'`. Among the bidders, it misses:

- the 11 adapters built on `libraries/xeUtils`, which sets the content type in the shared library;
- `application/json;charset=...` (eskimi, oprx, rixengine);
- custom headers (asterio, and appnexus, mediafuse and winr in test mode);
- prebidServerBidAdapter's publisher-configured headers.

`(no body)` rows only send a `Content-Type` on a `GET`. Core stops sending a `Content-Type` on bodiless requests in
[#16291](https://github.com/prebid/Prebid.js/pull/16291), which removes their preflight with no change to the module.

Nine of the bidders that are broken today (alkimi, anyclip, automatad, bedigitech, blue, glomex, ivs, lm_kiviads and
qwarry) are already removed on the `prebid-12.0` branch by [#16174](https://github.com/prebid/Prebid.js/pull/16174),
because their hosts no longer resolve.

## Checked, no trigger

- `1plusXRtdProvider` and `goldfishAdsRtdProvider` set `customHeaders: { Accept: 'application/json' }`. `Accept` is a
  CORS-safelisted header, so they send no preflight.
- `adspiritBidAdapter` and `displayioBidAdapter` pass `headers: { 'Content-Type': 'application/json' }` in their request
  options. `src/ajax.ts` has no `headers` option, so it is ignored and the request goes out as `text/plain`.
- `dasBidAdapter` sets `customHeaders: { 'Content-Type': 'text/plain' }`, which is safelisted.
- `yahooAdsBidAdapter` sends `contentType: 'text/plain'` and dropped its custom header in
  [#15226](https://github.com/prebid/Prebid.js/pull/15226), so it does not appear above.
